基本動態漸層背景

這是一個使用 CSS 實現的簡單動態漸層背景效果。通過 CSS 動畫屬性，背景顏色在不同色調之間平滑過渡。

這種效果使用了 CSS 的 linear-gradient 和 animation 屬性，通過設置背景尺寸為 400% 並使用 keyframes 動畫來移動背景位置，從而產生顏色流動的效果。

進階動態漸層背景

這是一個使用模糊效果和多層動畫的高級漸層背景。

這個版本使用了多個帶有模糊效果的漸層元素，並為每個元素設置了不同的動畫路徑，創造出更加豐富的視覺效果。

互動式動態漸層背景

移動滑鼠來與背景互動！

這個版本使用了 JavaScript 來監聽滑鼠移動事件，並根據滑鼠位置動態調整漸層元素的位置、旋轉角度和顏色，創造出與用戶互動的效果。

彩虹圓錐漸層背景

使用 conic-gradient 創建旋轉的彩虹效果。

這個版本使用了 CSS 的 conic-gradient 屬性來創建彩虹圓錐漸層效果，並添加了旋轉動畫和模糊覆蓋層，創造出柔和的彩虹背景效果。
